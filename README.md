# 考研择校资料库 · Kaoyan Hub

> 一个开源、零依赖、数据可校验的考研择校工具。所有数据来自教育部与研招网等公开渠道，欢迎 PR 补充。

**在线访问：** https://OWNER.github.io/kaoyan-hub/

---

## 这个项目解决什么问题

考研择校时，信息散落在几十个网站上：国家线在教育部的 PDF 里，学科评估在学位中心，
各校招生简章在各自的研招网，中间还夹着大量营销号的二手信息和过期数据。

这个项目把**能公开核实的那部分**集中到一个页面里，并且把数据和展示分开——
数据是纯 JSON，任何人都能审查、纠错、复用。

## 功能

| 模块 | 说明 |
|---|---|
| **院校库** | 79 所考研热门院校档案，支持按学校名 / 城市 / A+ 学科关键词搜索，按地区、层次（34所自划线 / 985 / 211 / 双一流 / 双非）、A·B 区筛选 |
| **改考预警** ⭐ | 63 条初试科目变动记录（2025/2026/2027 三个考研年度），覆盖「改考 408」「改回自命题」「数三改 396」等类型，可按年度 / 类型 / 来源可信度筛选，每条附来源链接并标注是否官方 |
| **专业详情** ⭐ | 22 所院校、83 个专业的逐专业档案：初试四门科目、**近三年复试线**（63 个专业）、**复试录取比**（56 个专业）、招录人数、学费学制，以及该校的科目变动历史 |
| **国家线** | 2026 年国家线全表（17 个学科门类 + 5 个单独划线的专业学位类别，A/B 区总分与单科线），并给出常见专业学位类别对应哪条门类线 |
| **数据图表** | 2021—2026 历年国家线趋势折线图（可切换门类、带十字准星与浮层）、2026 各门类总分线排序图、**各校 2026 复试线横向对比**（学硕/专硕分色，可切方向）、近年改考院校数量图、收录院校地区分布图 |
| **院校对比** | 最多同时对比 4 所院校，共 16 个维度：所在地、考区、层次、A+ 学科、A 类学科数、**改考提示、收录专业、初试科目、复试线、招录情况、学费学制**、研招网直链 |
| **资料链接** | 官方报名 / 调剂 / 大纲 / 学科评估等权威入口，每所院校附已验证的研招网直链 |

页面自适应手机与桌面，支持浅色 / 深色 / 跟随系统三种主题，无任何第三方依赖与埋点。

## 数据说明与来源

| 数据 | 来源 | 时效 |
|---|---|---|
| 2026 年国家线 | [研招网原文](https://yz.chsi.com.cn/kyzx/kp/202602/20260228/2293449093.html)、教育部公布的 PDF | 2026-02-28 |
| 2021—2026 历年国家线 | 研招网各年度公告 | 逐年核对 |
| 34 所自主划线院校名单 | [中国教育在线](https://www.eol.cn/e_ky/zt/common/gxmd/34.shtml) | 现行 |
| 学科评估（A+ / A 类学科数） | 教育部学位中心**第四轮**学科评估（2017）公开结果 | 2017 |
| 各校研招网 URL | 逐条访问验证 | 2026-08 |
| 初试科目变动（改考预警） | 学校/学院官网公告为主，考研资讯平台汇总为辅，逐条标注 | 2026-08 |
| 逐专业科目 / 复试线 / 报录比 | 各校研招网、学院官网，部分来自考研平台汇总 | 2026-08 |

**几点必须说清楚的：**

- 第五轮学科评估结果**未向社会公布**，本库只能用第四轮数据，它已经是 2017 年的了，只能作为参考而非当前实力的定论。
- 国家线只是「有资格进复试」的最低门槛。34 所自划线院校自己划线，通常远高于国家线。
- **「复试录取比」不是「报录比」**，请务必分清。复试录取比 = 复试人数 ÷ 拟录取人数，反映的是**进了复试之后被刷掉的比例**；
  报录比 = 报考人数 ÷ 录取人数，反映的是初试的竞争激烈程度。**报考人数绝大多数学校根本不公布**，
  所以本库里 `applied` 字段几乎全是 `null`，只有极少数学校（如中央财经大学的官方录取简报）能拿到。
  看到「复试录取比 1.48:1」不要误以为是「1.48 人报 1 个」——那是 37 个人进复试录 25 个。
- **逐专业数据目前覆盖 79 所中的 22 所**，这是本项目最需要社区补充的部分。原因很实在：
  很多学校把复试线、分专业招生计划以 **PDF 附件或图片**发布；部分官网还有反爬。
  已收录的记录都带 `confidence` 标记（official / secondary / partial），页面上也用「官方来源 / 二手来源」直接标出来。
  **查不到的字段一律留 `null`，不估算、不编造**——页面上的「未收录」「未公布」是真的没有，不是漏了。
- **分数线低不等于好考**。武大计算机学硕 2026 年复试线 295 分（接近国家线），但当年一志愿只录了 3 人——
  名额几乎全被推免占满。看分数线一定要同时看招生人数。
- 改考预警里标「二手来源」的条目来自考研资讯平台的汇总，**只作为预警信号**，报考前必须去目标院校官网核对当年招生专业目录。
- 一切以目标院校当年发布的官方招生简章为准。

## 本地运行

```bash
git clone https://github.com/OWNER/kaoyan-hub.git
cd kaoyan-hub
python3 src/merge_programs.py   # 合并逐专业数据（改了 programs-* 才需要）
node build.mjs                  # 把 data/*.json 注入模板，生成 index.html
```

然后直接用浏览器打开 `index.html` 即可，**不需要起服务器，也没有 npm 依赖**。

## 项目结构

```
.
├── index.html                       # 构建产物（已提交，GitHub Pages 直接托管）
├── build.mjs                        # 构建脚本：data/*.json → index.html，零依赖
├── src/
│   ├── template.html                # 页面模板（改样式和交互改这里）
│   ├── make_schools.py              # 由原始调研数据生成 schools.json
│   └── merge_programs.py            # 合并各批 programs-*.json → programs.json
└── data/
    ├── schools.json                 # 院校档案
    ├── national-lines-2026.json     # 2026 国家线全表
    ├── national-lines-history.json  # 历年国家线趋势
    ├── exam-changes.json            # 初试科目变动（改考预警）
    ├── programs.json                # 逐校逐专业（合并产物，勿直接改）
    ├── programs-base.json           # 逐专业数据 · 基础批
    ├── programs-cs-batch1.json      # 逐专业数据 · 计算机头部院校批
    └── resources.json               # 资料链接与常识提示
```

**改数据只改 `data/*.json`，然后跑 `node build.mjs`。** 改样式或交互改 `src/template.html`。
不要直接编辑 `index.html`——它会被构建覆盖。

## 参与贡献

最需要的是数据，按优先级：**① 逐专业复试线与报录比**（`data/programs.json`）、
