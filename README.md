# 考研择校资料库 · Kaoyan Hub

> 一个开源、零依赖、数据可校验的考研择校工具。所有数据来自教育部与研招网等公开渠道，欢迎 PR 补充。

**在线访问：** https://Nishino0525Nanase.github.io/kaoyan-hub/

---

## 这个项目解决什么问题

考研择校时，信息散落在几十个网站上：国家线在教育部的 PDF 里，学科评估在学位中心，
各校招生简章在各自的研招网，中间还夹着大量营销号的二手信息和过期数据。

这个项目把**能公开核实的那部分**集中到一个页面里，并且把数据和展示分开——
数据是纯 JSON，任何人都能审查、纠错、复用。

## 功能

| 模块 | 说明 |
|---|---|
| **院校库** | 79 所考研热门院校档案，支持按学校名 / 城市 / A+ 学科关键词搜索，按地区、层次（34所自划线 / 985 / 211 / 双一流 / 双非）、A·B 区筛选 |
| **专业方向** ⭐ | 按方向查全部院校：**计算机 / 电子信息 0854（非计算机）/ 金融 / 会计 MPAcc** 四个方向切换，一张表列出每个项目的初试科目、近三年复试线、分数线口径、招录、学费学制与来源。附 **0854 二级方向完整清单**（12 个代码）与 MPAcc 的 300 分制说明。**0854 已覆盖 75 所**，另 4 所经查证确实不开设，页面上把「查证过不招」和「还没查」分开标 |
| **改考预警** ⭐ | 63 条初试科目变动记录（2025/2026/2027 三个考研年度），覆盖「改考 408」「改回自命题」「数三改 396」等类型，可按年度 / 类型 / 来源可信度筛选，每条附来源链接并标注是否官方 |
| **专业详情** ⭐ | 77 所院校、583 个专业的逐专业档案：初试四门科目、**近三年复试线**（509 个专业，其中 273 个标了口径、208 个带单科线）、**复试录取比**（110 个专业）、招录人数、学费学制，以及该校的科目变动历史 |
| **国家线** | 2026 年国家线全表（17 个学科门类 + 5 个单独划线的专业学位类别，A/B 区总分与单科线），并给出常见专业学位类别对应哪条门类线 |
| **数据图表** | 2021—2026 历年国家线趋势折线图（可切换门类、带十字准星与浮层）、2026 各门类总分线排序图、**各校 2026 复试线横向对比**（学硕/专硕分色，可切方向）、**复试录取比排行**（进复试后被刷掉多少）、近年改考院校数量图、收录院校地区分布图 |
| **院校对比** | 最多同时对比 4 所院校，共 16 个维度：所在地、考区、层次、A+ 学科、A 类学科数、**改考提示、收录专业、初试科目、复试线、招录情况、学费学制**、研招网直链 |
| **名额结构与复试细则** ⭐ | 14 个头部院校计算机方向项目的**推免/统考名额拆分**、复试差额比、初试复试权重、有无机试、复试考什么、淘汰规则。统考名额 ≤10 或推免占比 ≥80% 时页面显式警告 |
| **数据新鲜度** ⭐ | 每块数据多久没更新，按 6/12 个月分三档着色；按当前月份给季节提醒（8 月大纲、9 月专业目录、2—3 月国家线、3—4 月调剂） |
| **资料链接** | 官方报名 / 调剂 / 大纲 / 学科评估等权威入口，每所院校附已验证的研招网直链 |

页面自适应手机与桌面，支持浅色 / 深色 / 跟随系统三种主题，无任何第三方依赖与埋点。

## 自动化

仓库配了四个 GitHub Actions，不需要人盯着：

| 任务 | 频率 | 做什么 |
|---|---|---|
| **构建校验** | 每次 PR / push | 校验所有 JSON 语法；拦住「改了 data 但没重跑 `merge_programs.py` / `build.mjs`」的提交 |
| **链接体检** | 每月 | 把 data/ 里全部 205 条 URL 拉一遍，404/410 的自动开 Issue 列出是哪个文件哪一行 |
| **数据源守望** | 每周 | 抓研招网、教育部、学位中心 + 43 所研招网，比对内容指纹；变了就开 Issue，命中「初试科目调整 / 改考 / 408」等关键词的高亮置顶 |
| **Pages 部署** | 每次 push main | 自动构建并发布 |

守望任务按月份只跑当季该跑的目标（比如调剂只在 3—5 月盯，改考公告只在 4—9 月盯），既省流量也少误报。

**这些任务只做预警，不做自动取数。** 各校页面结构差异太大，自动解析必然出错，
而本项目的底线是宁可留空也不出错误数据。所以它告诉你「这页变了、出现了改考关键词」，
取数仍然是人工（或人在 AI 辅助下）完成。

## 数据说明与来源

| 数据 | 来源 | 时效 |
|---|---|---|
| 2026 年国家线 | [研招网原文](https://yz.chsi.com.cn/kyzx/kp/202602/20260228/2293449093.html)、教育部公布的 PDF | 2026-02-28 |
| 2021—2026 历年国家线 | 研招网各年度公告 | 逐年核对 |
| 34 所自主划线院校名单 | [中国教育在线](https://www.eol.cn/e_ky/zt/common/gxmd/34.shtml) | 现行 |
| 学科评估（A+ / A 类学科数） | 教育部学位中心**第四轮**学科评估（2017）公开结果 | 2017 |
| 各校研招网 URL | 逐条访问验证 | 2026-08 |
| 初试科目变动（改考预警） | 学校/学院官网公告为主，考研资讯平台汇总为辅，逐条标注 | 2026-08 |
| 逐专业科目 / 复试线 / 报录比 | 各校研招网、学院官网，部分来自考研平台汇总 | 2026-08 |
| 0854 二级方向目录 | 国务院学位委员会办公室《电子信息等 8 种专业学位类别专业领域指导性目录》（工程教指委〔2021〕1 号） | 2021-01-13 |

**几点必须说清楚的：**

- 第五轮学科评估结果**未向社会公布**，本库只能用第四轮数据，它已经是 2017 年的了，只能作为参考而非当前实力的定论。
- 国家线只是「有资格进复试」的最低门槛。34 所自划线院校自己划线，通常远高于国家线。
- **「复试录取比」不是「报录比」**，请务必分清。复试录取比 = 复试人数 ÷ 拟录取人数，反映的是**进了复试之后被刷掉的比例**；
  报录比 = 报考人数 ÷ 录取人数，反映的是初试的竞争激烈程度。**报考人数绝大多数学校根本不公布**，
  所以本库里 `applied` 字段几乎全是 `null`，只有极少数学校（如中央财经大学的官方录取简报）能拿到。
  看到「复试录取比 1.48:1」不要误以为是「1.48 人报 1 个」——那是 37 个人进复试录 25 个。
- **逐专业数据目前覆盖 79 所中的 47 所**，这是本项目最需要社区补充的部分。原因很实在：
  很多学校把复试线、分专业招生计划以 **PDF 附件或图片**发布；部分官网还有反爬。
  已收录的记录都带 `confidence` 标记（official / secondary / partial），页面上也用「官方来源 / 二手来源」直接标出来。
  **查不到的字段一律留 `null`，不估算、不编造**——页面上的「未收录」「未公布」是真的没有，不是漏了。
- **分数线低不等于好考**。武大计算机学硕 2026 年复试线 295 分（接近国家线），但当年一志愿只录了 3 人——
  名额几乎全被推免占满。看分数线一定要同时看招生人数。
- **财经院校的分数线口径要看清**。不少学校只公布「经济学门类校线」而不公布逐专业院线，
  两者可能差几十分（西南财经就是典型）。本库每条 `lines[].note` 都标了口径是校线、院线还是一志愿复试线，
  页面图表悬停也能看到。**跨学校比较分数线前，先确认两边是同一口径。**
- **同一专业换个学院，线可能差几十分**。对外经贸 020204 金融学：中国金融学院 324 分，
  国际经济贸易学院 360 分，差 36 分。中山大学计算机方向专硕，计算机学院 379 分、
  软件工程学院 314 分，差 65 分。选学院有时比选专业更影响上岸。
- **复试线只是入场券，进了复试还会刷人**。同济计算机学硕 2026 年复试 230 人只录 26 人（复试录取比 8.85），
  南开软件工程专硕线只有 290 分但复试 83 人录 19 人。反过来西安交大计算机专硕复试 61 人录 60 人，
  几乎不刷。图表页的「复试录取比排行」就是看这个的。
- **⚠ 会计专硕 MPAcc 是 300 分制，不能和别的方向比。** 初试只考 199 管理类综合能力（200 分）+ 204 英语二（100 分），
  满分 300，初试不考政治。MPAcc 的「250 分」和普通专硕的「350 分」完全没有可比性。页面上 MPAcc 的分数线全部单独标了「300 分制」。
- **⚠ 0854 电子信息很多学校不按二级代码划线。** 哈工大、上交是全校 0854 统一划线（2026 年 310 / 315 分），
  东南也主要划到大类校线 320 分；南邮、南航、东南信院则用 085400 统一代码招生，通信/光电/控制都装在里面，
  招生目录上看不到 085402 这类代码。逐二级代码划线的只有电子科大、西电、杭电等少数。
  同校不同方向线差可能极大——南航 2026 年通信 370 分、航天光电信息 264 分，差 106 分。
- **⚠ 名额比分数线重要。** 北京大学计算机学硕 2026 年计划 173 人，其中推免 157 人，
  统考只剩 16 个；上海交大计算机学硕统考 5 人；复旦计算机学硕统考 6 人。
  这类专业的复试线再低也不代表好考——名额本身就没有。页面在统考名额 ≤10 或推免占比 ≥80% 时会显式警告。
- **名额数据的匹配是保守的。** 一条名额记录常常是「学院 + 专业代码」级别，而一个代码下可能有多个方向
  （上交 085400 底下有计算机、AI、软件工程等）。如果按学校+代码粗暴匹配，会把一个学院的总名额
  重复显示到每个方向上——那是错误数据。所以页面只在**学院能对上**时才显示，对不上宁可显示「未收录」；
  只能对上代码的会标注「该代码合计口径，非本方向单独数据」。
- **图表都标注了截断**。复试线对比图只画分数最高的前 28 个项目、复试录取比图只画最高的 20 个，
  图下都写明了还有多少条没显示——不做无声截断。
- 改考预警里标「二手来源」的条目来自考研资讯平台的汇总，**只作为预警信号**，报考前必须去目标院校官网核对当年招生专业目录。
- 一切以目标院校当年发布的官方招生简章为准。

## 本地运行

```bash
git clone https://github.com/Nishino0525Nanase/kaoyan-hub.git
cd kaoyan-hub
python3 src/merge_programs.py   # 合并逐专业数据（改了 programs-* 才需要）
node build.mjs                  # 把 data/*.json 注入模板，生成 index.html
```

然后直接用浏览器打开 `index.html` 即可，**不需要起服务器，也没有 npm 依赖**。

## 项目结构

```
.
├── index.html                       # 构建产物（已提交，GitHub Pages 直接托管）
├── build.mjs                        # 构建脚本：data/*.json → index.html，零依赖
├── src/
│   ├── template.html                # 页面模板（改样式和交互改这里）
│   ├── make_schools.py              # 由原始调研数据生成 schools.json
│   └── merge_programs.py            # 合并各批 programs-*.json → programs.json
├── scripts/
│   ├── check-links.mjs              # 链接体检（零依赖）
│   └── watch-sources.mjs            # 数据源守望（零依赖）
└── data/
    ├── schools.json                 # 院校档案
    ├── national-lines-2026.json     # 2026 国家线全表
    ├── national-lines-history.json  # 历年国家线趋势
    ├── exam-changes.json            # 初试科目变动（改考预警）
    ├── programs.json                # 逐校逐专业（合并产物，勿直接改）
    ├── programs-base.json           # 逐专业数据 · 基础批
    ├── programs-cs-batch1.json      # 逐专业数据 · 计算机第一批
    ├── programs-cs-batch2.json      # 逐专业数据 · 计算机第二批
    ├── programs-ee-batch1.json      # 逐专业数据 · 0854 非计算机方向
    ├── programs-acc-batch1.json     # 逐专业数据 · 会计专硕 MPAcc
    ├── programs-fin-batch1.json     # 逐专业数据 · 金融头部院校批
    ├── track-catalog.json           # 方向定义、0854 二级目录、MPAcc 说明
    ├── quota-retest.json            # 推免/统考名额拆分、复试细则
    ├── watch-targets.json           # 数据源守望清单
    └── resources.json               # 资料链接与常识提示
```

**改数据只改 `data/*.json`，然后跑 `node build.mjs`。** 改样式或交互改 `src/template.html`。
不要直接编辑 `index.html`——它会被构建覆盖。

## 参与贡献

最需要的是数据，按优先级：**① 逐专业复试线与报录比**（`data/programs.json`）、
