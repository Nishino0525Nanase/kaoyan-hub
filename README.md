# 考研择校资料库 · Kaoyan Hub

> 一个开源、零依赖、数据可校验的考研择校工具。所有数据来自教育部与研招网等公开渠道，欢迎 PR 补充。

**在线访问：** https://OWNER.github.io/kaoyan-hub/

---

## 这个项目解决什么问题

考研择校时，信息散落在几十个网站上：国家线在教育部的 PDF 里，学科评估在学位中心，
各校招生简章在各自的研招网，中间还夹着大量营销号的二手信息和过期数据。

这个项目把**能公开核实的那部分**集中到一个页面里，并且把数据和展示分开——
数据是纯 JSON，任何人都能审查、纠错、复用。

## 功能

| 模块 | 说明 |
|---|---|
| **院校库** | 79 所考研热门院校档案，支持按学校名 / 城市 / A+ 学科关键词搜索，按地区、层次（34所自划线 / 985 / 211 / 双一流 / 双非）、A·B 区筛选 |
| **国家线** | 2026 年国家线全表（17 个学科门类 + 5 个单独划线的专业学位类别，A/B 区总分与单科线），并给出常见专业学位类别对应哪条门类线 |
| **数据图表** | 2021—2026 历年国家线趋势折线图（可切换门类、带十字准星与浮层）、2026 各门类总分线排序图、收录院校地区分布图 |
| **院校对比** | 最多同时对比 4 所院校的所在地、层次、A+ 学科、A 类学科数、研招网直链 |
| **资料链接** | 官方报名 / 调剂 / 大纲 / 学科评估等权威入口，每所院校附已验证的研招网直链 |

页面自适应手机与桌面，支持浅色 / 深色 / 跟随系统三种主题，无任何第三方依赖与埋点。

## 数据说明与来源

| 数据 | 来源 | 时效 |
|---|---|---|
| 2026 年国家线 | [研招网原文](https://yz.chsi.com.cn/kyzx/kp/202602/20260228/2293449093.html)、教育部公布的 PDF | 2026-02-28 |
| 2021—2026 历年国家线 | 研招网各年度公告 | 逐年核对 |
| 34 所自主划线院校名单 | [中国教育在线](https://www.eol.cn/e_ky/zt/common/gxmd/34.shtml) | 现行 |
| 学科评估（A+ / A 类学科数） | 教育部学位中心**第四轮**学科评估（2017）公开结果 | 2017 |
| 各校研招网 URL | 逐条访问验证 | 2026-08 |

**几点必须说清楚的：**

- 第五轮学科评估结果**未向社会公布**，本库只能用第四轮数据，它已经是 2017 年的了，只能作为参考而非当前实力的定论。
- 国家线只是「有资格进复试」的最低门槛。34 所自划线院校自己划线，通常远高于国家线。
- 逐校逐专业的复试线、报录比、推免占比等数据**目前未收录**——这类数据分散在各校历年公告里，
  单靠爬取容易出错。数据结构已经预留字段，欢迎按 [CONTRIBUTING.md](CONTRIBUTING.md) 提交你核实过的数据。
- 一切以目标院校当年发布的官方招生简章为准。

## 本地运行

```bash
git clone https://github.com/OWNER/kaoyan-hub.git
cd kaoyan-hub
node build.mjs        # 把 data/*.json 注入模板，生成 index.html
```

然后直接用浏览器打开 `index.html` 即可，**不需要起服务器，也没有 npm 依赖**。

## 项目结构

```
.
├── index.html                       # 构建产物（已提交，GitHub Pages 直接托管）
├── build.mjs                        # 构建脚本：data/*.json → index.html，零依赖
├── src/
│   ├── template.html                # 页面模板（改样式和交互改这里）
│   └── make_schools.py              # 由原始调研数据生成 schools.json
└── data/
    ├── schools.json                 # 院校档案
    ├── national-lines-2026.json     # 2026 国家线全表
    ├── national-lines-history.json  # 历年国家线趋势
    └── resources.json               # 资料链接与常识提示
```

**改数据只改 `data/*.json`，然后跑 `node build.mjs`。** 改样式或交互改 `src/template.html`。
不要直接编辑 `index.html`——它会被构建覆盖。
