# 数二逐题 · 专题真题刷题

[在线刷题](https://Nishino0525Nanase.github.io/kaoyan-hub/math2/)

收录 2007—2026 年考研数学二共 455 道真题，按 118 个细分专题组织，支持年份、章节、题型和掌握状态筛选。题图和参考结果均为本目录静态资源；详细讲解附原发布链接。

支持选择题核对、错题历史、收藏、思路笔记、计时、学习统计和 JSON 备份恢复。进度只保存在当前浏览器，不自动跨站点或设备同步。从此前站点切换过来，可先导出学习记录，再在本页导入。

## 维护

本目录是一套独立静态网页，`index.html`、`styles.css`、`app.js` 是界面源文件，`data/questions.json` 为题目记录，`assets/` 为题图和答案图。所有资源使用相对路径。无需运行根目录的构建脚本生成本目录内容，既有 Pages 工作流会随 main 分支提交一并发布。

2007 年 24 题；2008—2020 年每年 23 题；2021—2026 年每年 22 题。题库与图片完整性、主要交互已检查；未做手机实机视觉验证。

来源和已知排印订正在 `data/meta.json`、逐题记录与 `provenance/` 中。原题整理与第三方图片的权利归各自权利人；根目录 MIT 许可不对本目录的第三方题图和题目资料授予额外权利。详情见 [来源说明](NOTICE.md)。
